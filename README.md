# pca-pacmap-timbre-segmenter
Timbre reorganizer: auto-segments an audio file by onset/novelty detection, extracts MFCC features per segment, and reorders them by timbral similarity (via PCA and/or PaCMAP) from similar-to-different or vice versa, with an interactive 2D/3D plot for clicking segments to audition and exporting the reordered mix.
